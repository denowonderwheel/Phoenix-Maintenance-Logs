Grease history — danger zone

Wipe grease history deletes every grease log entry without re-seeding (use this to start the per-row tracker from scratch). Inspections are not affected.
Set per-row baseline writes a baseline cycle so the dashboard treats every row's B/W/C counter as "last serviced at cycle X" until newer entries override it. Useful right after wiping.
