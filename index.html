Manual PDF location — used by the Ref column links

Paste the full path or URL to your copy of Manual OMM_45032_EN_01.pdf. Once set, clicking a Ref like 4.2.2 in any inspection table opens the manual to that exact page.

Examples and tips ▾

Same folder as Phoenix_Tracker.html:
Manual OMM_45032_EN_01.pdf

Mac, full path:
/Users/dj/Documents/Phoenix/Manual OMM_45032_EN_01.pdf
(Tip: drag the file into the address bar of any browser, copy the resulting URL — that's the form that always works.)

Windows, full path:
C:\Users\DJ\Documents\Phoenix\Manual OMM_45032_EN_01.pdf

Hosted online (Dropbox / Google Drive / your park's intranet):
https://example.com/manuals/phoenix.pdf
(Best option if you want the Claude artifact view to also be able to open it — sandboxed iframes can't reach local files.)

Heads-up: Local file links only work when you open Phoenix_Tracker.html directly in your browser. The Claude artifact view is sandboxed and can't open file:// links — you'd need a hosted URL for that.
